# BuildWise

BuildWise is a Software Engineering guidance platform designed to help students build software projects through a structured, practical engineering journey.

## Vision

BuildWise aims to connect Software Engineering concepts with real project development by guiding students through the different stages of building a software project — from understanding the problem and defining requirements to design, development, testing, deployment, and maintenance.

## Project Status

🚧 **Currently in Product Discovery**

The project is being developed iteratively using an Agile approach.

## Engineering Journey

The project will follow a complete Software Engineering lifecycle:

1. Problem Discovery
2. Product Definition
3. Requirements Engineering
4. System Analysis
5. System Design
6. Development
7. Testing
8. Deployment
9. Maintenance

## Purpose of This Repository

This repository documents both the development of BuildWise and the Software Engineering process used to build it.

The goal is not only to build the product, but also to demonstrate how a software system can be systematically analyzed, designed, implemented, tested, and evolved.
